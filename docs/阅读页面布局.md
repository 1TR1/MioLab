# 阅读页面布局 1.7.1

本版参考用户提供的阅读截图调整布局。根据用户后续说明，不采纳截图的纸面颜色，继续使用现有的跟随系统、浅色、深色和暖纸色主题。

## 1.7.1 上下留白与摄像头适配

- 阅读容器遵循系统提供的完整安全区；只让纸面背景延伸到屏幕边缘。竖屏避开前置摄像头、刘海及灵动岛，横屏保留侧边安全距离，底部避开主屏幕指示条。
- 正文在章节页眉和状态页脚之间，上下各增加 24 点留白。额外留白不随阅读工具栏显隐变化。
- 顶栏通过顶部对齐的覆盖层固定在安全区顶端下方 8 点，底栏通过底部对齐的覆盖层固定在安全区底端上方 8 点，左右各留 12 点。
- 两个工具栏使用各自的玻璃容器，仅作淡入淡出，不再使用共同的 Spacer 和整体缩放定位。
- 本轮只修改界面布局及发布版本，书库结构和阅读偏好保持兼容；正文区域变小后，实际屏幕页数会重新计算。

## 阅读页面

- 默认收起浮动工具栏和系统状态栏。轻点正文中央，或轻点左上章节名称，显示返回书架、目录、搜索、书签、笔记及排版设置。
- 章节名称位于左上方，正文和页脚各自拥有独立区域。工具栏覆盖显示，显隐时不改变正文高度，不触发分页跳动。
- 可重排书籍采用约 18 点的基础正文字号、两字首行缩进、两端对齐及适当段间留白。章节文件开头的章标题居中加粗；兼容已经导入的 TXT 阅读副本，不重复插入标题。
- 保留用户保存的字号倍率、字体选择、行距、边距和翻页方式。原文已带首行空格时不再叠加缩进；引文、图注、表格等段落不加小说式首行缩进。
- 左下显示设备电量及 24 小时时间，右下显示分页。电量读取不可用时隐藏电池图标，不使用示意读数。
- PDF 与固定版式 EPUB 显示全书原始页码，不对书页内部字体、标题和段落重新排版。
- 可重排书籍在水平分页模式下，显示当前章节文件的实际屏幕页码，例如 `1/32`。字号、边距或屏幕尺寸改变后重新计算。如果一个章节文件含多个目录条目，页数仍以该文件为单位。
- 垂直滚动模式显示全书阅读百分比。目录定位继续使用既有的稳定“位置”索引，与实际屏幕页码分开，保证书签、批注和续读定位兼容。

## 自行导入

交付文件为 `output/MioLib-1.7.1-unsigned.ipa`，保留 `com.miolib.reader` 应用标识及 USB 文件共享。使用用户自己的侧载／签名工具导入并签名；本轮不连接设备、不安装应用。

## 验证范围

Release 构建、核心测试、包内资源及版本核验详见“验证记录”。离线示意生成器为 `tools/preview-reader-layout.py`，使用项目实际 Readium CSS 与自写样文，生成 `output/preview-reading-layout/index.html`。其中页眉页脚为 SwiftUI 布局的 HTML 示意，时间、电量为预览固定值，不是应用截图。

本轮自动浏览器因安全策略不允许 `file:` 地址而未能查看预览；尚未执行 iPhone / iPad 真机的外观、旋转、触摸翻页及续读交互验收，不以编译和核心测试替代这些检查。
