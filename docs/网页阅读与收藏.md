# 网页阅读、网址书籍与收藏（1.15.4）

## 打开与保存

1. 点击书架左上角地球图标，或打开“我的 → 网页阅读与收藏”。
2. 选择“打开内置浏览器”，输入或粘贴网址后点击“前往”。不输入协议时默认使用 HTTPS；HTTP 网站需输入完整的 `http://` 地址。
3. 正常浏览网页，点击下方书签按钮保存当前页面。标题可修改，留空时使用网站域名；重定向后保存的是实际页面地址。
4. 再次进入网页阅读，点击收藏即可打开链接。也可通过“添加网址收藏”直接保存已有链接。

浏览器底部依次提供后退、前进、刷新／停止和收藏；右上角菜单可以分享当前链接和切换广告过滤。已收藏页面显示实心书签，点击可编辑。收藏列表支持搜索标题或网址，长按／侧滑可编辑、分享或删除；删除需确认。

## 导出至书架

1. 在“已保存的网址”中长按网址，选择“导出至书架”；也可向右滑动该行，点击同名按钮。
2. 选择目标书架后点击“导出”。导出保存书目和来源网址，原收藏继续保留。
3. 导出成功后可直接选择“编辑书籍”，或回到书架，通过“编辑标题、封面与链接”修改。封面支持照片、图片文件及裁切；提取正文后也支持从书页选取或在阅读时使用当前页。
4. 网址书籍使用普通书目的标题搜索、列表／封面视图、书架四宫格、收藏、已读、移动、批量编辑、删除撤销、笔记导出与完整备份。

同一规范化链接重复导出会返回原书，不覆盖自定标题、封面、所在书架或进度。若原书被软删除，重新导出会恢复原 ID 并放入本次选择的书架。网址书籍和原收藏独立保存；编辑或删除其中一个，不改变另一个。

修改书籍链接时会重置旧正文、进度和已读状态。已有摘录、批注与颜色继续保留，旧定位清除，避免跳到新文章的错误段落。改名和换封面不会重置正文与进度。

## 选择阅读模式与水平翻页

从书架打开无缓存记录的网址书籍时，会弹出“选择缓存卷”。勾选并确认后开始下载，点“暂不缓存”可立即继续打开。有离线正文或已有缓存选择记录的书会直接打开。之前开启过阅读模式且已有离线正文时会进入阅读器，其余情况打开原网页。右上角选择“关闭阅读模式”会回到原网页，并记住关闭状态。已有离线正文时，从笔记进入仍可直接跳转。

正文提取使用 Mozilla Readability 0.6.0，实现类似 Safari 阅读模式的去除导航和交互区的效果。每章保留标题、段落、列表、引用、代码和表格文字，尝试保存最多 20 张公开可下载的图片。离线副本只包含阅读所需的正文和资源。

提取成功后生成本地 EPUB，打开现有的普通书籍阅读界面，页眉、页脚、上下工具栏与安全区布局保持一致：

- 在“阅读设置 → 阅读方式”选择“水平分页”，即可左右滑动翻页；默认阅读偏好即为水平分页，也可选择垂直滚动。
- 主题、字号、字型、行距和页边距沿用普通书籍的阅读设置。
- 正文中的章节标题形成目录。进度条、目录定位、书内搜索、书签、高亮、批注和页级笔记使用原来的阅读器功能。新缓存保留可提取的同页文字注释，打开方式随阅读设置。 [书内注释](阅读页面布局.md#书内注释)
- 关闭后再次点击“阅读模式”，使用已保存的正文并恢复位置；从笔记打开时，直接进入正文定位。
- 轻点正文中央可显示工具栏。左上角退出会直接关闭该书，阅读位置和该书的模式开关都会保存。阅读菜单和书架长按菜单均可分享原链接、导出正文 EPUB。

缓存正文可离线阅读，并随备份保存。遇到网站登录、验证或加载失败时，可处理原网页上的提示，再点“继续缓存”。缓存保留原来的正文节点，引文和批注仍能定位到已读章节。

图片下载不复制浏览器 Cookie；需要登录、防盗链、HTTP 网络策略不允许或下载失败的图片可能缺失，保留可用的替代文字。仅图片、视频和复杂交互页面建议继续使用原网页。行内链接和强调保留文字，复杂表格保留行列文字，不承诺还原原网站的全部版式。

## 按卷缓存与删除

- 打开的书指向文库8的书籍详情、目录或正文时，卷名及章节顺序来自网站目录，包含目录列出的插图章。没有分卷目录的站点按“全书”缓存，从当前文章沿明确的相邻章链接收集正文。
- 原网页和阅读模式都可在右上角「⋯ → 选择缓存卷」补选卷。阅读模式中轻点正文中央可显示工具栏。缓存选择弹窗会标出已缓存的卷，确认后下载勾选的内容，并复用已保存的正文。暂停后可点“继续缓存”，或重新选择未完成的卷。
- 确认选择后，该书会保存缓存记录。下载尚未完成或后来清理了缓存时，可以从菜单重新选择。
- 在“我的 → 网页书籍缓存”选一本书，即可查看各卷的离线状态、添加要缓存的卷，或删除某一卷的缓存。书目、笔记和书签会保留，重新缓存同一章可恢复其原有定位。
- 旧版已缓存的文库8书籍首次打开缓存设置时会读取分卷目录。暂时无法读取目录时，可以先管理整本缓存。
- 网页书籍页显示下载章数，支持暂停和继续。返回书架、切换 App 或锁屏后，缓存可在 iOS 授予的后台时段内继续。iOS 26 及以上在允许时使用持续后台任务，较早版本使用短时后台任务。到期会保留已下载章节，返回 App 后自动续跑。[Apple 的持续后台任务说明](https://developer.apple.com/documentation/backgroundtasks/performing-long-running-tasks-on-ios-and-ipados)
- 缓存失败后会逐步延长重试间隔，等待时可以处理其他书。只有至少两次失败、自该书开始缓存已满 30 秒，且没有任何已保存章节时，才显示缓存失败。已有部分正文时可继续阅读，剩余章节会自动重试。
- 所选卷就绪后，“阅读模式”可离线搜索、跳章和水平翻页。阅读中完成缓存后，打开目录或搜索会使用新副本，并保留当前阅读位置。
- 每本书支持最多 2,000 章，章节资源上限为 512 MB。达到上限或遇到站点限制时会提示原因，已下载正文仍会保留。

## 阅读模式切换上一章／下一章

1. 进入阅读模式后，轻点正文中央显示工具栏。
2. 点击底部的“上一章／下一章”；右上角阅读操作菜单也提供相同入口，不必退出到浏览器。
3. 所选卷内未下载的章节按需联网提取。切到未选卷时，可以在原网页继续，或去缓存设置添加该卷。目录、搜索与进度范围覆盖已缓存的章节。

支持页面中的 `rel=next/prev`，以及“上一章、下一章、上一節、下一節、上一页、下一页”等明确标签。只按站点实际链接切换，不把章节数字自增猜作下一章。Wenku8 的“上一页／下一页”和 `preview_page/next_page` 字符串导航均会识别，返回 `index.htm` 的链接作为目录边界，不会缓存为正文。Wenku8 目录链接导出为书籍时，首次阅读模式会按目录实际顺序进入首章。

每章正文和图片保留独立源副本，合并阅读副本原样保留旧章的正文节点和资源路径，追加章节不删除旧笔记。书目 ID、收藏、封面与原始来源链接保持不变，重开时继续上次章节和页内位置。1.9.0 的单页缓存首次切章时只补导航元数据，不重新生成已经标注过的正文。

切章过程中可取消。网络失败、未找到相邻章、链接返回目录、站点需要登录或验证时，当前正文继续保留，可在提示中选择“在原网页查看”。Wenku8 的插图章可保留图片与切章入口，无法下载的图片显示替代说明。

## 保存图片

在阅读模式长按已显示的插图，点击“保存图片”。这会使用离线副本中的图片，断网时也能保存。在原网页长按图片时，使用系统菜单“保存图像”。首次保存时由 iOS 按需询问相册权限。若此前拒绝授权，可在系统设置中打开 MioLib 的照片权限。

1.10.0 已补齐最终安装包中的 `NSPhotoLibraryAddUsageDescription` 与兼容系统路径使用的 `NSPhotoLibraryUsageDescription`，修复旧包缺少用途声明而被系统终止的触发点。发布打包脚本会检查这两个字段。权限用途依据 [Apple 添加照片权限说明](https://developer.apple.com/documentation/bundleresources/information-property-list/nsphotolibraryaddusagedescription) 及 [照片访问权限说明](https://developer.apple.com/documentation/bundleresources/information-property-list/nsphotolibraryusagedescription)。实际保存和允许／拒绝权限后的交互仍需真机验证。

## 广告过滤

默认开启过滤，地球图标变为绿色盾牌时表示规则已经就绪。规则在首次访问前通过 WebKit 编译；准备失败时显示说明，可刷新重试或在菜单中关闭过滤后访问。

- 阻止来自 21 个明确广告域名及其子域的第三方请求，包括 DoubleClick、Google Syndication、百度联盟和广点通等。
- 隐藏明确的常见广告容器，不使用泛化的 `ad` 子串去匹配所有元素。
- 拦截脚本自动打开的新窗口，用户点击的正常新窗口链接在当前窗口打开。
- 开关变化会重载当前页面，以恢复或移除原来的广告资源与占位。

这是内置基础规则集，不能保证过滤全部网站广告；网站自有广告、混入正文的广告和绕过规则的脚本可能仍然显示。网页显示或登录异常时，可关闭过滤并重新加载。不会绕过网站登录、付费限制或验证码。

实现使用 [WebKit 内容拦截规则](https://webkit.org/blog/3476/content-blockers-first-look/) 和 [WKContentRuleListStore](https://developer.apple.com/documentation/webkit/wkcontentruleliststore)，规则只用于内置网页浏览器，电子书阅读器的本地页面不受影响。网页浏览器允许用户输入的 HTTP 网页，其他网络模块仍沿用原有 ATS 设置。

## 本机数据与备份

收藏保存在书库 SQLite 中，包括稳定 ID、标题、网址、添加时间和最近成功访问时间。相同规范化网址再次保存会更新标题；不同章节、查询参数与锚点保留为各自的链接。网址只支持 HTTP／HTTPS，不保存嵌入账号密码的网址。

备份版本 6 保存卷目录、缓存选择和删卷后保留的章节定位。此前版本 5 支持尚未合并的章节，版本 4 支持已合并章节，版本 3 支持未提取网址与旧式单页缓存，纯本地书库使用版本 2。当前应用兼容恢复版本 1 至 6。

单独的网址收藏只保存链接。原网页需要联网，滚动位置由浏览器页面管理。用户确认缓存后，已下载的正文和阅读器里的进度随书库保存。网站登录由 WebKit 的本机网站数据管理，网站 Cookie、密码、浏览器导航历史和网站缓存均不包含在书库备份中。原网页沿用网站排版，阅读模式沿用本地 EPUB 排版设置。

## 真机验收

Windows／WSL 无法运行 iOS WebKit。核心测试覆盖网址书籍、稳定章节资源、正文合并、旧笔记位置保留、重复章节、向前插入、目录拒绝、插图章、改链失败隔离、备份恢复后继续追加与旧缓存迁移。Node／jsdom 测试运行实际 Readability 和应用脚本，检查正文、导航语义、目录边界、危险链接、登录／验证页拒绝与插图章。真实 Wenku8 GBK 页面也进行了离线 DOM 解析验证。这些检查不能替代 iPhone／iPad 上的 WebKit、相册权限和触摸验收。

建议依次验证：收藏文章 → 导出到子书架 → 修改标题与封面 → 打开原网页 → 阅读模式 → 水平翻页 → 调整主题与字号 → 高亮批注 → 退出续读 → 断网打开已保存正文 → 从笔记返回原文 → 备份恢复。再验证链接修改、重复导出、无正文页面、登录后重试、取消提取、原网页跳转后提取、图片缺失，以及横竖屏与大字号的工具栏触控。

1.10.0 追加验收：Wenku8 目录进入首章 → 下一章 → 上一章 → 老章高亮定位 → 退出续读 → 断网回看缓存章 → 备份恢复后继续下一章；再验证首末章、插图章、取消／断网失败、登录验证页面。浏览器长按图片分别检查首次授权、允许后保存和拒绝后重试，确认不再退出应用。

提取脚本本机测试：先执行 `npm --prefix output/web-reader-validation install --no-save jsdom@26.1.0`，再执行 `node --test tools/test-web-article-extractor.cjs`。依赖仅放在忽略的 `output` 目录，不进入 App 或源码交付包。
