# 封面、批量编辑与末页进度

MioLib 1.3.0 新增书架书籍封面选择、书页封面选择和书架批量编辑，并修正末页进度。

## 从书籍选择书架封面

1. 长按书架，选择“编辑标题与封面”；也可先点击书架“编辑”，再点击书架或铅笔。
2. 点击“从书架中的书籍选择”。来源包含此书架及其子书架，可按书名搜索。
3. 选择一张书籍封面，裁切后点击“使用此封面”，最后在书架编辑页点击“保存”。

只显示已有实际封面的书籍。所选图片会保存为独立的书架封面快照，并随完整书库备份保存；来源书籍改封面、移动或删除后，书架仍保留所选图片。

## 从书页选择书籍封面

1. 长按书籍，选择“编辑标题与封面”，再点击“从书页选择封面”。
2. 用上一页、下一页、进度滑块或目录定位。PDF 还支持页码输入及缩略图。
3. 点击“选用此页”，完成裁切后，在书籍编辑页点击“保存”。

也可正常阅读时翻到想用的页面，点击右上角“⋯ → 将本页设为封面”。裁切确认后立即保存。

PDF 使用完整页面，文字书使用当前显示的书页内容；若 iPad 显示双页，可在裁切时选取其中一侧。独立封面预览不会写入阅读位置、最近阅读或笔记。封面不会修改原始书籍文件。

## 主页面批量编辑

1. 在书架点击左上角“编辑”。列表和封面视图均保留原布局。
2. 勾选书籍或点击“全选”；再点“全选”位置的“取消全选”可清空。
3. 点击底部“批量编辑”，按需选择收藏、已读／未读和移动位置，点击“应用”。未修改的属性保持原样，阅读位置保留。
4. 也可直接使用底部“移动”或“删除”。删除后支持书架底部“撤销”。

编辑模式中的铅笔可以逐本编辑标题和封面；书架点击后可编辑名称及封面。切换搜索或筛选时，只保留仍然可见的书籍选择，避免修改其他结果。完成后点击左上角“完成”。

## 末页显示 100%

- PDF 到最后一页显示并保存 100%；只有一页的 PDF 也显示 100%。
- EPUB、TXT 和转换后的 MOBI / AZW3，以最后阅读资源的可见尾端判断完成。即使末页页首定位尚不足 100%，末页仍显示 100%。
- 阅读位置仍保存真实 Locator 或页内坐标，退出后可以返回相同位置。
- 正文与书架都显示相同百分比。未完成时向下取整，不会把 99.9% 四舍五入成 100%。
- 进度滑块拖至最右端会定位文字书最后资源的尾端。

## 本轮验证

核心测试覆盖单页 PDF、文字书可见尾端、百分比边界、批量编辑范围与回滚、书页封面更新时保留最新进度、书架封面快照随备份恢复。iOS Release 构建通过。

2026-11-17，用户在 iPhone 13 / iOS 18.3.2 上确认：批量收藏与移动正常；EPUB 书页封面及书架书籍封面均可保存；EPUB 末页与单页 PDF 均显示 100%。详细记录见 `docs/验证记录.md`。
