# 玻璃界面与阅读导航

此文记录 1.4.0。1.5.0 已进一步调整目录布局、字号轨道、书架封面与阅读空间，当前说明见 [书架与阅读空间](书架与阅读空间.md)。

MioLib 1.4.0 / build 5 调整书架、导航和阅读目录。直接覆盖更新即可保留现有书库。

## 玻璃界面

- iOS / iPadOS 26 起，操作层使用系统 Liquid Glass、交互响应及 GlassEffectContainer；底部导航沿用系统新样式。
- iOS 17–18 使用系统通透材质、边缘高光和浮动胶囊导航，按压和选中高光使用约 240–260 毫秒的短弹簧。当前 iPhone 13 / iOS 18.3.2 使用此兼容方案。
- 开启“减少动态效果”后关闭自定义缩放和弹簧；开启“减少透明度”后改用清晰实底。正文和封面不叠加玻璃模糊。
- 原生接口依据 [Apple Liquid Glass 文档](https://developer.apple.com/documentation/swiftui/glass) 与 [WWDC25 新设计说明](https://developer.apple.com/videos/play/wwdc2025/323/)。iOS 18 的兼容效果不等同于 iOS 26 的系统折射效果。

## 书架

1. 点击右上角三点，在“显示方式”选择列表、封面或网格。网格使用更紧凑的卡片；三种布局均支持原有多选、批量编辑和封面操作。
2. 原来“文件夹／最近／收藏／已读”的整行分段栏改为一个下拉菜单。搜索仍覆盖全书库。
3. 在三点菜单选择“最近阅读／书名／导入时间”。布局和排序全局共享，重新打开、进入其他文件夹和恢复备份后保留。
4. 旧版选择封面视图的用户更新后仍使用封面视图。旧版备份缺少新字段时自动提供默认值。

## 我的

底部导航现在为“书架／我的”；iPad 侧边栏同步调整。

- 阅读记录：进入全部阅读笔记与书签，查看收藏及已读数量。笔记保留搜索、批注编辑和回到原文。
- 阅读偏好：主题、字体、排版、翻页、书架布局和排序。
- 数据管理：完整备份与恢复、全部笔记 Markdown / JSON 导出。
- 关于 MioLib：实际应用版本、书库数量及第三方许可。

## 目录与定位

1. 阅读时点击“目录”，首先看到这本书自带的目录。点击展开箭头显示下级章节，点击章节名回到正文。
2. 目录下方固定显示滑动条和输入框。滑动时预览编号，松手后定位；输入有效编号后点击“跳转”，直接显示目标页。
3. PDF 与固定版式 EPUB 按页码定位；流式 EPUB、TXT、MOBI 和 AZW3 使用稳定的“阅读位置”编号，界面明确标注。该编号不随字号和屏幕变化，不能当作印刷页码或当前排版后的屏幕页数。
4. 没有内置目录的 PDF 显示空目录说明，仍可用下方控制跳页；右上角“缩略图”可打开原生 PDF 缩略图。
5. 无效、空白及越界输入不会跳转；单页书禁用滑动条。末页定位继续保持 100% 规则。

## 排版格点

字号每格 5%，行距及页边距每格 0.1；拖动值会吸附到最近格点，并提供轻触感。iOS 26 使用系统格点，旧系统补充可见圆点。阅读偏好仍自动保存。

## 真机验收

2026-11-17，用户在 iPhone 13 / iOS 18.3.2 上确认：下拉筛选与“书架／我的”正常，网格布局和书名排序重开后保留；三页 EPUB 的内置目录及两种跳页方式正常；排版格点吸附正常，浮动导航与玻璃工具栏动效顺畅。这是实际交互确认，尚无设备帧率、峰值内存或原生 iOS 26 玻璃效果的测量记录。

回归步骤如下；横屏、iPad 分屏及大书库设备性能仍待单独检查：

1. 选择网格及书名排序，重新打开应用并进入文件夹，检查选择记忆；切换下拉范围和编辑模式。
2. 在“我的”打开笔记，再返回；打开字体排版，拖动滑块检查格点与触感。检查深色、大字号和“减少动态效果”。
3. 在三页 EPUB 通过内置目录和滑动条定位第三页；输入 1 跳回首页。打开 PDF，检查页码跳转、缩略图和单页 100%。
4. 检查横屏及 iPad 分屏、千本书库滚动和导入期间响应。当前未记录这些设备实测结果。
