# 样本来源

`sample-kf7.mobi`、`sample-kf8.azw3`、`sample-huffdic.mobi`、`sample-drm.mobi` 来自 libmobi v0.12 的官方测试样本，原文件分别为 sample-cp1252.mobi、sample-ncx.mobi、sample-unicode-huffdic.mobi、sample-drm-v1.mobi。

上游：https://github.com/bfabiszewski/libmobi/tree/v0.12/tests/samples

AZW3 样本保留原始二进制，仅更换扩展名以验证 KF8 入口。DRM 样本仅用于验证明确拒绝导入，不解密。

中文样书为本项目自行编写。
